# Changelog

## 1.0.0
- Per-project window colors (border and title bar), rules, hotkeys, manual assignment.
- Claude app in-app text rules and sidebar chat marks; browser tab marks.
- Window switcher (Ctrl+Alt+W) and optional Alt+Tab replacement with live previews.
- Configurable border thickness (1 to 8 px).
- Modern Windows 11 style settings window (light and dark).
